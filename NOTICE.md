# Notice (English)

This is a personal fan project, built to run my own legally purchased Steam copy of **Shenmue I & II** on my own Xbox. There is no intent of piracy or fraudulent use whatsoever.

**What this project does:**
- Downloads the game exclusively through the end user's own Steam account, via official Steam login (QR code), with no bypass of that verification.
- Does not distribute, has never distributed, and will never distribute any game file or any SEGA / Shenmue Production Committee asset.
- Does not include any third-party mods (translation, HD textures, widescreen patch) — only the mechanism that applies them, for users who already own them on their own.
- Is documented publicly and in good faith: the sole intent is to share, for free, with other fans who also already own the game, a way to play it at the best possible quality on an Xbox with Dev Mode.

**Commitment:** if SEGA, the Shenmue Production Committee, or Valve believe this project infringes any right, even unintentionally (and despite AI-assisted research done in good faith to try to understand whether I might be infringing anything), please get in touch (open an issue in this repository) — it will be made private or taken down immediately, no questions asked.

**On forks and copies:** this code is open for transparency, not to become a piracy tool. I do not authorize forks or redistributions that remove, replace, or bypass the Steam-based ownership verification used to unlock access to the game — see the additional condition in `LICENSE`.

I'm just a fan who wants to play Shenmue on Xbox. And to extend that to others who, like me, own the original game and want to do the same. Nothing more than that.
